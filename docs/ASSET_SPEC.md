# PPPYLLES 美術素材規格

所有素材放在 `public/assets/` 底下，並在 `public/assets/manifest.json` 登記。
**沒有登記或讀取失敗的素材，遊戲會自動使用程式畫的占位圖**，所以可以一張一張慢慢替換。

## 共通規則

- 格式：**PNG（需要透明背景）**，背景圖可用 PNG 或 WebP
- 風格：2D 插畫、柔和療癒、整套風格一致（同一位 AI／同一組提示詞）
- **不要**在圖中放文字、浮水印、邊框
- 檔名用英文小寫，例如 `fish/guppy.png`
- 更新同一張圖時請換檔名（例如 `guppy-v2.png`），避免玩家瀏覽器讀到舊快取

## 1. 主畫面背景（水族箱）

> **目前採用：房間場景** — 木造房間裡有一面大型水族窗，魚游在窗內，陸地寵物走在木地板上。
> 已使用：`bg/room-landscape-v1.webp`（橫向）。**還缺直向版本**。
>
> 房間場景的背景需要在 manifest 寫 `layout`（水族箱水域、魚游動範圍、地板高度的位置比例），
> 新圖交給 Claude 量測並設定即可。直向版建議：同一個房間，水族窗佔畫面上方約 2/3、
> 下方約 1/4 是木地板（陸地寵物走動），左右的貓跳台／小屋可以縮小或省略。

需要 **兩張同風格** 的背景，遊戲會依螢幕方向自動切換：

| manifest 欄位 | 用途 | 尺寸 |
|---|---|---|
| `background` | 電腦、手機橫拿 | **2560 × 1440** |
| `backgroundPortrait` | 手機直拿 | **1290 × 2796** |

**配置：**

```
┌──────────────────────────┐
│  ← 上方約 12%：資源列 →   │ 不放重點、偏暗
│                          │
│                          │
│      中段水域：魚游動區    │ 乾淨、不要太花
│                          │
│                          │
├──────────────────────────┤ ← 從底部算起約 18% 的位置
│     沙地（陸地寵物走動）    │ 上緣大致平坦
│        [ 底部選單 ]        │ 中央不放重點
└──────────────────────────┘
四周邊緣約 10% 可能被裁切
```

- 圖片以**底部對齊**縮放，沙地永遠在畫面最下方
- 背景請畫滿整張，不需要為介面留白（介面是半透明的浮在上面）
- **不要畫進背景**：魚與任何生物、氣泡、文字、按鈕
- 光束、水草可以畫；若有畫，在 manifest 的 `effects` 把 `lightRays` 或 `plants` 設為 `false`，關掉程式產生的版本

**提示詞參考：** 放鬆療癒的水族箱內部、正面平視、柔和藍綠色調、上方水面透光、底部沙地、遠景模糊岩石與水草、中央留白、無生物、無文字、2D 遊戲背景插畫

## 2. 魚（水中寵物）

| 項目 | 規格 |
|---|---|
| 畫布 | **512 × 512**（或寬大於高，例如 512 × 320），透明背景 |
| 方向 | **側面、頭朝右**（遊戲會自動左右翻轉） |
| 留邊 | 魚身佔畫布寬度約 90%，上下置中 |
| 大小 | 不用管實際大小，遊戲依魚種設定縮放；**圖的寬度 = 魚從嘴到尾巴的長度** |
| 動畫（選用） | 橫向排列的連續動畫格，例如 4 格就是 2048 × 512，在 manifest 寫 `"frames": 4` |

需要的魚種（`manifest.json` 的 `fish` 欄位）：

| id | 名稱 | 外型 |
|---|---|---|
| `guppy` | 孔雀魚 | 小型、扇形大尾巴 |
| `neon` | 霓虹燈魚 | 小型、身上藍色發光條紋 |
| `clown` | 小丑魚 | 橘白相間 |
| `angel` | 神仙魚 | 身形高挑、長背鰭腹鰭 |
| `betta` | 鬥魚 | 華麗長鰭 |
| `discus` | 七彩神仙 | 圓盤形 |
| `arowana` | 龍魚 | 修長、金屬光澤鱗片 |
| `jelly` | 月亮水母 | **正面朝上**（傘在上、觸手往下），不翻轉 |

**品質（灰／綠／紫／金／紅）不需要另外畫**，遊戲會在魚周圍加上對應顏色的光暈。若之後想讓高品質的魚有不同外觀，可再追加 `guppy_gold.png` 這類變體。

## 3. 陸地寵物

| 項目 | 規格 |
|---|---|
| 畫布 | **512 × 512**，透明背景 |
| 方向 | **側面、頭朝右** |
| 位置 | 角色**腳底貼齊畫布底部往上約 5%**，左右置中 |
| 動畫（選用） | 走路循環，橫向排列，例如 6 格 = 3072 × 512，`"frames": 6` |

| id | 名稱 |
|---|---|
| `crab` | 寄居蟹（初始贈送） |
| `turtle` | 陸龜 |
| `capybara` | 水豚 |

## 4. 沙地（選用）

如果背景圖已經包含沙地就不需要。若想讓沙地單獨一層：`sand`，**2560 × 400**，上緣可以有自然的起伏但盡量平坦。

## 5. 裝飾（預留）

裝飾系統尚未開放。之後會需要：512 × 512 透明 PNG、正面平視、底部貼齊畫布底緣。

## 登記方式

把圖放進 `public/assets/fish/guppy.png` 之後，修改 `public/assets/manifest.json`：

```json
"fish": {
  "guppy": { "src": "fish/guppy.png" },
  "neon": null
}
```

有動畫格時：

```json
"guppy": { "src": "fish/guppy-swim.png", "frames": 4, "fps": 8 }
```

或者直接把圖交給 Claude，由 Claude 處理去背、裁切、命名與登記。
