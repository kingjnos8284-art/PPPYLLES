# PPPYLLES 美術素材規格

所有素材放在 `public/assets/` 底下，並在 `public/assets/manifest.json` 登記。
**沒有登記或讀取失敗的素材，遊戲會自動使用程式畫的占位圖**，所以可以一張一張慢慢替換。

## 共通規則

- 格式：**PNG（需要透明背景）**，背景圖可用 PNG 或 WebP
- 風格：2D 插畫、柔和療癒、整套風格一致（同一位 AI／同一組提示詞）
- **不要**在圖中放文字、浮水印、邊框
- 檔名用英文小寫，例如 `fish/guppy.png`
- 更新同一張圖時請換檔名（例如 `guppy-v2.png`），避免玩家瀏覽器讀到舊快取

## 0. 房間主題

目前有兩套主題，玩家可在「設定 → 房間主題」切換，選擇會存在存檔中：

| id | 名稱 | 檔案 |
|---|---|---|
| `forest` | 森林精靈屋 | `bg/forest-landscape-v1.webp`、`bg/forest-portrait-v1.webp` |
| `stellar` | 星空水晶館 | `bg/stellar-landscape-v1.webp`、`bg/stellar-portrait-v1.webp` |

主題設定在 `public/assets/manifest.json` 的 `themes`，每個主題有橫／直背景、`layout`（水族箱水域、游動範圍、寵物位置）與縮圖。
寵物位置可指定給特定寵物（`pet`），或標成備用位置（`fallback`）：當一般位置超出畫面或被底部選單擋住時才使用。
新增主題：沿用相同構圖（左側貓跳台、中央水族箱、右下兩張狗床），交給 Claude 量測位置即可。

## 1. 主畫面背景（水族箱）

> **目前採用：房間場景** — 木造房間裡有一面大型水族窗，魚游在窗內，陸地寵物走在木地板上。
> 已使用：`bg/room-landscape-v1.webp`（橫向）、`bg/room-portrait-v1.webp`（直向）。
> 直向版的陸地寵物走在水族窗下方的櫃子檯面上（手機底部的地板會被選單蓋住）。
>
> 房間場景的背景需要在 manifest 寫 `layout`（水族箱水域、魚游動範圍、寵物行走高度的位置比例），
> 新圖交給 Claude 量測並設定即可。

需要 **兩張同風格** 的背景，遊戲會依螢幕方向自動切換：

| manifest 欄位 | 用途 | 尺寸 |
|---|---|---|
| `background` | 電腦、手機橫拿 | **2560 × 1440** |
| `backgroundPortrait` | 手機直拿 | **1290 × 2796** |

**配置：**

```
┌──────────────────────────┐
│  ← 上方約 12%：資源列 →   │ 不放重點、偏暗
│                          │
│                          │
│      中段水域：魚游動區    │ 乾淨、不要太花
│                          │
│                          │
├──────────────────────────┤ ← 從底部算起約 18% 的位置
│     沙地（陸地寵物走動）    │ 上緣大致平坦
│        [ 底部選單 ]        │ 中央不放重點
└──────────────────────────┘
四周邊緣約 10% 可能被裁切
```

- 圖片以**底部對齊**縮放，沙地永遠在畫面最下方
- 背景請畫滿整張，不需要為介面留白（介面是半透明的浮在上面）
- **不要畫進背景**：魚與任何生物、氣泡、文字、按鈕
- 光束、水草可以畫；若有畫，在 manifest 的 `effects` 把 `lightRays` 或 `plants` 設為 `false`，關掉程式產生的版本

**提示詞參考：** 放鬆療癒的水族箱內部、正面平視、柔和藍綠色調、上方水面透光、底部沙地、遠景模糊岩石與水草、中央留白、無生物、無文字、2D 遊戲背景插畫

## 3. 陸地寵物（貓、狗）

住在房間裡：貓在貓跳台、狗在狗窩旁。位置寫在背景 manifest 的 `layout.pets.spots`，
寵物會在自己的位置輪流坐著／趴著／待機／睡覺，貓偶爾換到貓跳台的另一層，點擊播放互動動畫與愛心對話框。

已完成：
- `cat_tuxedo` OREO（賓士貓）— 固定在貓跳台頂層（素材包 `housepets_motion_v1`）
- `cat_tabby` LUNA（虎斑貓）— 固定在貓跳台第二層（素材包 `tabby_cat_motion_v1`）
- `dog_dachshund` NANA（長毛臘腸）

規劃中：再 1 隻貓、1 隻狗（共 3 貓 2 狗）。
固定位置寫在背景 manifest 的 `layout.pets.spots[].pet`；沒有指定位置的寵物會自動找空位。

**新寵物請沿用同一套規格：**

| 項目 | 規格 |
|---|---|
| 畫格 | 384 × 384，6 欄；一般動作 4 列 24 幀，互動 2 列 12 幀，10 FPS |
| 動作 | `sit` 坐著、`lie` 趴著、`idle` 站立待機、`sleep` 睡覺、`interact` 點擊（使用不含愛心的 clean 版） |
| 腳底 | **y = 340**（錨點 0.5, 0.885），所有動作一致 |
| 方向 | 貓頭朝右、狗頭朝左（與現有兩隻相同即可，遊戲會依位置自動翻轉） |
| 比例 | 與現有的貓、狗同一比例 |

## 登記方式

把圖放進 `public/assets/fish/guppy.png` 之後，修改 `public/assets/manifest.json`：

```json
"fish": {
  "guppy": { "src": "fish/guppy.png" },
  "neon": null
}
```

有動畫格時：

```json
"guppy": { "src": "fish/guppy-swim.png", "frames": 4, "fps": 8 }
```

或者直接把圖交給 Claude，由 Claude 處理去背、裁切、命名與登記。
